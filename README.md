# Fysik.com

Fysik.com är en enkel hemsida för elever som läser Fysik 1a på gymnasiet.  
Syftet med sidan är att hjälpa användare att lära sig grunderna inom fysik på ett tydligt och enkelt sätt.

## Funktioner

- Startsida som är fylld med information om fysik
- En sida med viktiga fysikformler
- Quiz med frågor och automatisk rättning med hjälp av JavaScript
- Bild på solsystemet + information

## Tekniker som används

- HTML
- CSS
- JavaScript

## Filer

- index.html
- formler.html
- frågor.html
- style.css
- JavaScript.js
